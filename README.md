# Translate VK Bot 🌍

VK-бот-переводчик, собранный по конкурсным требованиям: чистая архитектура,
тесты, Docker, работа с внешними API и продуманный пользовательский путь.

## ✨ Что умеет

- Перевод на 20 языков через MyMemory (основной) с автоматическим
  fallback на LibreTranslate.
- 🔁 Быстрый перевод на русский с автоопределением исходного языка —
  одна кнопка.
- 🧠 Запоминает языковые пары пользователя. При следующем входе
  предлагает продолжить с той же парой — с инлайн-подтверждением.
- 📜 История переводов (последние 5 запросов) через /history.
- 🎛 Двухуровневый выбор языка с флагами:
  - популярные (6 языков) — инлайн под сообщением;
  - «Ещё →» — полный список на обычной клавиатуре (до 50 кнопок,
    без пагинации).
- 🛡 Валидация ввода: длина текста, корректность кода языка,
  защита от перевода в тот же язык.
- 📉 Устойчивость к лимитам: rate-limit 429 → fallback → понятное
  сообщение пользователю.

## 🚀 Быстрый старт

1.  Скопируйте .env.example в .env и впишите токен сообщества VK
    (права: messages, photos).

    Команда: cp .env.example .env

2.  Установите зависимости и запустите (Windows / Git Bash):

        python -m venv .venv
        source .venv/Scripts/activate
        pip install -r requirements.txt
        python -m app.main

    Для Linux / macOS активация: source .venv/bin/activate

3.  Напишите боту в VK команду /start.

## 🐳 Docker

    docker compose up --build

## 🧭 Пользовательский сценарий

1. /start — приветствие и описание фич. Если у пользователя уже есть
   сохранённая пара src→tgt, бот предлагает её продолжить
   (✅ Продолжить / 🔄 Сменить пару).
2. Кнопка «Выбрать пару языков» открывает **инлайн-меню популярных**:
   «🔍 Автоопределение» и 6 популярных исходных языков с флагами.
3. Кнопка **«Ещё →»** открывает **полный список языков на обычной
   клавиатуре** внизу экрана — сразу все оставшиеся языки с флагами,
   без пагинации. Внизу списка — навигация:
   - «← К популярным» — **скрывает нижнюю клавиатуру** (через
     `EMPTY_KEYBOARD`) и возвращает компактное инлайн-меню;
   - «Сразу на русский» — режим авто→ru в один клик;
   - «Отмена» — сбросить диалог.
4. После выбора исходного языка бот предлагает выбрать **целевой**
   тем же способом (инлайн популярные + «Ещё →» для полного списка).
   В полном списке целевых языков доступны кнопки
   «← К популярным», «← Другой исходный» и «Отмена».
5. После выбора целевого языка — приглашение отправить текст. Бот
   показывает «Отправьте текст для перевода: 🔍 авто → 🇬🇧 English» и
   возвращает главное меню внизу экрана.
6. После перевода — инлайн-кнопки «Ещё перевод / Сменить пару /
   История».

### Почему «Ещё →» открывает обычную клавиатуру

VK ограничивает **инлайн-клавиатуры 10 кнопками**, а **обычные —
50** (10 рядов × 5 кнопок). Поэтому «Ещё →» переключает нижнюю
клавиатуру на «полный список языков»: пользователь видит сразу все
20 языков без пагинации. Инлайн-меню остаётся для компактного
быстрого выбора популярных.

### Как добавить новый язык

Всё централизовано в `app/services/validators.py`. Добавьте одну
строку в `SUPPORTED_LANGUAGES`:

    "eo": "🏳️ Esperanto",

и, если нужно, добавьте код в `POPULAR_LANGUAGES` для показа в
инлайн-меню. Флаг и название автоматически появятся везде: в
инлайн-меню, в обычной клавиатуре полного списка, в истории и в
результате перевода. Больше нигде править не нужно —
`label_to_code()` строит обратную карту из того же dict.

## ⚠️ Ограничения

- Состояние «жду текст» хранится в памяти процесса — переживает перезапуск
  только пользовательская пара языков (она в БД).
- MyMemory ограничивает 500 символов на запрос — валидатор это соблюдает.
- Публичный инстанс LibreTranslate (translate.terraprint.co) нестабилен.
  Для надёжного fallback раскомментируйте сервис `libretranslate` в
  `docker-compose.yml` и укажите в `.env`
  `LIBRETRANSLATE_URL=http://libretranslate:5000/translate`.
